## 测试隔离边界

为保护已有机器范围安装，测试仅在安装器启动边界增加 `/currentuser` 和测试目录 `/D=`，并关闭创建快捷方式。下载到的安装器文件本身未修改。

首次自动重启暴露了测试隔离失误：Windows Shell 启动没有继承父进程的隔离环境，短暂读取了真实用户配置。默认输出路径的两处引用被改为测试安装目录，随后已恢复为原安装目录的 `outputs`；FFmpeg 的检测时间戳因这次启动刷新，因此该配置文件并非逐字节恢复。现有程序和用户项目文件未被替换或删除。

补充测试只在安装器启动参数中移除 `--force-run`，由验收脚本携带隔离环境重新启动安装后的应用。该轮验证了配置隔离及文件保留，不能单独当作自动重启的证据；自动重启的证据来自首次测试。两轮本地记录分别保存在 `artifacts/qa/real-github-update-initial.json` 和 `artifacts/qa/real-github-update.json`（验收产物，不随源码提交）。
