# 使用指南

界面语言：设置 → 外观与任务 → 界面语言。支持简体中文、英文和跟随 Windows 系统，保存后立即生效；字幕文本和文件名不会被翻译。见 [界面语言](LANGUAGES.md)。

快捷键：设置 → 外观与任务 → 编辑快捷键。二级页面可录入组合键、清除、重置单项或恢复全部默认值；保存后同时应用到界面和 mpv 视频窗口。播放器与字幕页共享播放按键，冲突会标记并拒绝保存。输入框保留正常文本编辑快捷键，Esc 退出全屏固定保留；部分 Win 组合键可能被系统占用。返回设置保留草稿，离开设置提示应用或放弃。

AI 操作确认：导航栏“MCP 交互”接收文件夹访问及转码申请，查看详细内容后批准或拒绝，见 [MCP 指南](MCP.md)。

字幕工程统一使用 ASS；SRT 与 SSA 导入后在 ASS 工程中编辑，导出时再转换为目标格式。后续精细打轴与可视化排版范围见 [字幕评估](SUBTITLE-ROADMAP.md)。

Windows x64 媒体处理应用，内置 mpv 播放器，使用外部 FFmpeg 执行转码和波形分析。

## 功能

- 单文件：媒体信息、输出轨道、预设、处理计划与转码。
- 参数：常用项位于主面板；11 类详细设置，支持按名称搜索、滤镜顺序和真实引擎专用选项。见 [参数覆盖](PARAMETERS.md)。
- 预设：新建、复制、编辑、删除、完整 JSON 导入导出，可用于单文件与批量。
- 批量：共享参数、单项覆盖、整批检查和输出自动编号。
- 任务：GUI 与 AI 任务共用独立页面；暂停、继续、取消、等待项排序、筛选、搜索、耗时与预计剩余时间。历史保留最近 1000 条已结束记录，每页 50 条；支持单条、跨页及全部匹配记录删除。完整记录、参数和日志在“查看详细信息”二级页面中显示。
- 硬件：设置页显示 CPU、内存及实体显卡摘要，二级页面查看完整设备与编解码信息。使用 DXGI 64 位容量和可用的 NVIDIA 驱动接口读取显存，区分专用显存、系统可用容量、共享内存及虚拟适配器；支持手动更新，MCP 提供同一快照。
- 实时监控：任务页底部悬浮显示 CPU/GPU 整体占用及内存；展开显示所有 CPU 逻辑线程、各实体 GPU 的编码器/解码器、显存与共享内存占用。每秒刷新，缺失指标标为不可用，离开任务页或隐藏窗口后停止采样。
- 界面：圆角下拉菜单采用滚轮和右侧自绘滑条，支持键盘选择；硬件摘要和任务项采用嵌套卡片。普通展示文字不可选中，输入框和字幕编辑区保留编辑能力，专用复制按钮仍可使用。
- 操作反馈：异步按钮即时显示加载图标，页面顶部持续显示处理状态；取消任务保持“取消中”直至进程结束，波形生成与字幕保存显示动画。
- 退出：托盘退出使用应用内弹窗，显示未完成任务及 MCP 状态；确认后显示关闭进度，关闭窗口仍隐藏到托盘。
- mpv 播放器：播放/暂停、停止、拖动进度、毫秒时间跳转、音量/静音、0.25–4 倍速、全屏、PNG 截图、前后逐帧、A–B 循环、单文件/列表循环、播放列表、音轨/字幕选择、外部音轨/字幕和延迟调整。
- 字幕编辑：SRT/ASS/SSA 导入、ASS 工程、时间与文本编辑、条目多选及批量操作、查找替换、撤销重做、基础 ASS 样式、播放定位与工程预览。项目管理创建独立媒体项目和 ASS，编辑页只打开或关闭已有工程，60 秒自动保存，并保留工程备份与恢复缓存；SRT/ASS/SSA 导出单独执行。
- ASR 工作台：导入模型，选择音轨与区间生成初稿，ASS/SRT 导出及追加/替换到 ASS 工程。接入 whisper.cpp large-v3、Qwen3-ASR、MOSS 适配器和通用 JSONL 后端，识别参数与运行环境分别在二级页管理；识别共用任务队列。见 [ASR 指南](ASR.md)。
- 引擎：检测 PATH、选择本地 FFmpeg、按需下载固定 Gyan 9.0.2 Essentials、SHA-256 校验和版本切换。
- MCP：本机 HTTP、Bearer 凭据、目录与操作权限、20 个工具、硬件与指南资源、长任务查询与控制、去重，与 GUI 共用队列。新增操作申请和人工审核；已授权操作仍可直接执行。可复制通用连接信息，由 AI 按平台完成接入；预览隐藏凭据。内置 7 份 Markdown 指南，支持“更快”“画质好”“文件小”的选型指导；参数参考来自共享定义，专用选项来自当前 FFmpeg 帮助。
- 中文界面、明暗主题、文件拖入、系统托盘。关闭窗口后任务与 MCP 继续，播放器暂停；从托盘退出时提示。

处理编码器按实际引擎列出，包含 H.264/H.265/AV1/VP9、硬件编码和多种音频编码；支持无损封装、轨道筛选、音轨/字幕提取、滤镜、剪辑、色彩处理与图像输出。

## 配置处理引擎

安装包不捆绑 `ffmpeg.exe` / `ffprobe.exe` 处理引擎。播放可独立使用；转码和波形需要在**设置 → 转码引擎 · FFmpeg** 中选择或下载引擎。独立引擎存放于 `%LOCALAPPDATA%\Muxivra\engines\ffmpeg`。

## 基本操作

单文件：导入 → 选择参数与输出轨道 → 检查计划 → 开始处理。单文件和批量默认输出到安装目录的 `outputs`，可另选目录；开发模式使用项目根目录的 `outputs`。目录自动创建，无法写入时会明确提示。

批量：添加文件 → 设置共享或单项参数 → 检查批次 → 提交。

任务列表默认显示输出文件名、来源、状态、编码及耗时；未完成项另显示进度和预计时间。使用上一页、下一页或页码跳转定位，每页固定 50 条，搜索与筛选应用于全部保留记录。进入详情再返回时保留原页码和筛选。

“查看详细信息”显示提交、开始、结束时间、毫秒精度的实际处理时长、进度、输出大小、进程退出码、输入/输出路径、完整参数、提交时的引擎、实际执行参数、处理事件和完整日志。日志每段最多 64 KiB，可继续翻段或查看日志文件；旧版本未保存的字段标为未记录。

只有已结束的记录可删除。可选择本页、跨页勾选或选择全部匹配记录，然后确认删除；删除记录及其日志会保留输入、输出媒体文件。等待、处理及暂停项不计入 1000 条历史上限，也不会被自动删除；超出上限时清理最早结束的记录。升级时旧历史自动迁移到每页最多 50 条的分页文件。

预览按视频显示比例布局，普通模式高度上限为 540px，且不超过窗口高度的 60%；竖屏和旋转视频保持比例，全屏另行适配。参数菜单仅避让实际遮挡区域。默认音量 50%，音量条和百分比输入框的方向键每次调整 5%；可直接输入整数百分比。

播放器下方的“播放设置与列表”包含精确跳转、逐帧、循环、轨道、延迟和列表。截图保存为新 PNG，不覆盖已有文件。播放器快捷键：空格播放/暂停，左右跳转，上下调音量，M 静音，F 全屏，Esc 退出全屏，S 截图，`.` 下一帧，`,` 上一帧；视频画面双击全屏。

字幕：项目管理 → 新建项目（媒体与可选初始字幕）→ 打开字幕编辑 → 编辑或新增条目 → 保存。项目文件页集中导入字幕、复制工程和导出。Q 设置起点，E 设置终点，左右移动 100ms，Ctrl+Z 撤销，Ctrl+Shift+Z 重做。快捷键跟随当前页面，点击按钮后仍生效；文字和数值编辑框保留编辑键，菜单和确认窗使用自身键盘操作。旧默认起止键自动迁移为 Q/E，已有自定义键保持；有冲突时保留旧键，可在设置中修改。时间在编辑状态中保存为整数毫秒；ASS/SSA 文件按其百分之一秒格式写入，导出时明确提示精度变化。

## 字幕项目与保存

字幕编辑和 ASR 工作台只处理项目管理创建的已有工程，共用安装目录 projects 下的独立项目。在项目管理的新建项目页导入媒体复制源文件、创建同名文件夹和 ASS，同名项目自动编号；“导入后删除原文件”默认不勾选，仅在副本校验和项目创建成功后执行。旧源目录工程不自动适配或迁移。项目管理提供搜索、打开、改名、删除到回收站及恢复；“复制工程”创建包含当前编辑内容的新项目。详见 [媒体项目](PROJECTS.md)。

手动保存与每 60 秒自动保存写入项目内 ASS，恢复缓存与最近 20 份备份也在项目中。外部修改冲突时停止覆盖，可复制工程保留恢复稿。项目文件页导入字幕先保留原始副本，再应用到当前 ASS；ASS、SSA 和 SRT 输出仍独立执行，SRT 模式限制 ASS 专属编辑项，导出前确认降级内容。

字幕编辑工作区固定在窗口内，整体页面不滚动，字幕列表和事件编辑区独立滚动。播放器详细设置入口位于控制栏最右侧，点击显示悬浮面板，可滚动配置跳转、循环、轨道、延迟和播放列表；展开不改变预览或条目区域的尺寸，Esc 优先关闭内部下拉框，再关闭设置面板。工程栏在无项目时展开，导入后收起到右侧编辑区下方；手动展开后向上显示悬浮面板，工作区大小与位置保持不变。视频填充始终为黑色。样式二级页保留播放器实例，内部滚动持续更新原生视频位置与裁剪。

项目文件页的导出除字幕文件外，还支持 FFmpeg 画面烧录和可切换字幕轨道：MKV 保留 ASS，MP4 转为 mov_text 并提示样式损失。视频导出使用提交时的字幕副本并进入统一队列。字幕编辑页底部“单文件处理”会先保存并生成快照，再将媒体和字幕转到单文件页；可在“字幕”卡片切换烧录/封装、保留或丢弃源字幕轨道，并使用全部转码参数，检查计划后再提交任务。输出默认位于项目 exports，可自行选择位置。

“跟随播放”默认关闭，开启后自动选中当前时间的对白并定位分页；同时显示的多条对白一起选中，注释不选中。编辑文本和事件属性时暂缓，退出输入框后恢复。搜索时停止跟随。

音频波形默认显示 15 秒，提供时间刻度、峰值、RMS、播放游标和当前字幕区间。鼠标置于波形上使用 Ctrl＋滚轮缩放横轴，Ctrl＋Shift＋滚轮缩放纵轴；也可使用各自的放大/缩小按钮。纵轴显示增益支持 ×0.25–×64，便于观察低音量句子的边界，仅改变显示，不调整源音频或播放音量。点击波形定位视频。播放超出当前视窗时自动切换，左右按钮可查看相邻范围，重置恢复 15 秒和纵轴 ×1。实际按视窗解码 48 kHz 音频，不再以整片 2000 个点显示。

字幕表格使用紧凑行，开始/结束时间在一行显示，长文本以省略号显示，选中后在右侧完整编辑。每页 50 条，可通过页码定位；搜索与替换应用于工程中的条目。选择条目后可复制、粘贴、删除、拆分或合并，批量操作作为一次历史操作撤销。带 ASS 覆盖标签的条目需手动拆分，避免切断标签或改变作用范围。合并保留第一条的样式与事件属性，并用换行连接文本。时间偏移支持指定范围及仅调整起点/终点；校验结果可以定位非法时间、空文本、缺失样式和重叠条目。

MCP 默认关闭。手动添加输入媒体目录，输出默认提供安装目录 outputs，其他输出可另行添加。启用后复制提示词发给 AI，内容仅含通用连接信息和服务器响应说明，由 AI 决定连接方式。见 [MCP 接入与指南](MCP.md)。

设置页未保存的参数会换色标记。离开时选择应用、放弃或继续编辑；应用过程中显示动画，失败保留草稿并停留原页。硬件详情子页返回时保留草稿。

## 适用范围

面向 Windows x64。支持本地单文件容器，不接受网络、UNC、HLS/DASH/concat 播放列表。支持内嵌和外部文本字幕烧录、时间区间剪辑以及基础 ASS 工程与样式编辑。频谱、拖动时间边界和视频上可视化排版仍属于后续范围，ASR 可生成供手动调整的字幕初稿；不执行 Aegisub Lua/MoonScript 插件。硬件编解码仍取决于显卡和驱动，当前未覆盖全部硬件。

## 软件信息与更新

设置页最底部的软件信息卡片显示当前版本、应用 GPL-3.0-only、实际 FFmpeg 构建许可和内置 mpv 许可，并提供 GitHub 仓库、问题反馈及 Releases 手动更新入口。启动时自动检查默认开启，可关闭；与其他设置一样，未保存修改换色并在离开时提示应用或放弃。关闭自动检查后仍可手动检查、下载并确认安装。

波形播放指示线按动画帧平滑移动并适配倍速，暂停、跳转和逐帧时立即校准。若播放器停止报告进度，外推最长 250ms 后停止；字幕事件编辑、跟随选择和写入时间仍使用播放器实际位置。
