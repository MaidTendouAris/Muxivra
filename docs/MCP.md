# 连接 AI 与内置指南

## 复制连接提示词

1. 在设置中手动添加 MCP 可访问的媒体目录，勾选需要的权限，启用 MCP。
2. 安装目录下的 `outputs` 自动创建并作为默认授权输出目录，无需再次选择；可添加其他输出目录。默认目录不可写时会提示，需手动选择可用目录。输出授权不会自动变成输入授权。
3. 点击“保存并复制完整连接提示词”。有草稿时先保存并启动服务，再复制；保存失败时不更新剪贴板。
4. 发送给 AI，由 AI 根据所在平台的 MCP 或本机执行能力决定连接方式。

提示词仅包含实际 URL、Streamable HTTP 传输、Bearer 凭据、请求头、超时、状态、应用路径、目录权限以及服务器返回内容说明。没有特定客户端的命令或配置模板。预览隐藏凭据；只发送给可信的 AI。服务只监听本机，远程 AI 平台需本机执行器，不能用远程环境的 127.0.0.1 访问这台电脑。

## 连接协议与返回内容

设置页“连接信息与凭据”可分别复制通用连接数据和凭据。认证为 `Authorization: Bearer <凭据>`，支持通过客户端自己的凭据机制或 `MUXIVRA_MCP_TOKEN` 环境变量提供；无需 OAuth。连接超时 15 秒，工具超时 60 秒。应用不修改客户端配置。

无会话 Streamable HTTP，仅 POST。请求头需要 `Content-Type: application/json` 和 `Accept: application/json, text/event-stream`。客户端完成 initialize 后发送 notifications/initialized，再发现工具、资源与 prompt；通知可能返回 202 空正文。initialize 的实际协议版本以协商结果为准，instructions 提供当前目录、默认输出路径、权限与硬件快照。

工具调用先检查 isError；成功响应的 content.text 为 JSON，错误文本说明原因。plan_transcode 只校验并返回计划和警告；submit_jobs 返回后台任务 ID，不代表完成，需 get_job 查询最终状态、耗时和输出。

## 工具

| 工具 | 作用 |
| --- | --- |
| inspect_media | 分析授权输入媒体的轨道、编码、尺寸、时长 |
| get_engine_capabilities | 读取实际 FFmpeg 编码器、解码器、滤镜及版本 |
| get_component_capabilities | 读取本机编码器或滤镜的真实选项、范围、默认值和枚举 |
| get_system_hardware | 读取硬件、显存来源、字段缺失状态和编解码能力；硬件加速未验证 |
| list_presets | 返回内置与用户预设的完整选项 |
| plan_transcode | 校验路径、参数及轨道，生成计划 |
| submit_jobs | 向 GUI 共用队列提交 1–500 项，requestKey 支持重试去重 |
| get_job / list_jobs | 查询授权任务的状态、进度、耗时、剩余时间、错误和输出 |
| cancel_job | 显式取消任务；运行项终止为异步，随后查询结果 |
| pause_job / resume_job | 保留进度暂停或继续任务 |
| move_job | 调整等待任务顺序 |
| list_media_files | 列出授权输入目录一层内的媒体，最多 500 项 |
| list_skills / read_skill | 发现或读取 7 份内置离线指南 |

## 内置 skills

| ID | 使用时机 |
| --- | --- |
| connection | 连接验证、协议与返回内容 |
| workflow | 分析、计划、提交、结果核验 |
| goals | “快一点”“画质好”“文件小”、兼容性与目标体积的取舍 |
| audio | AAC/M4A、MP3、FLAC、采样率、声道和音频滤镜 |
| video | 视频编码、封装、画面和轨道处理 |
| parameters | 当前应用的完整结构化参数、滤镜与范围 |
| troubleshooting | 任务状态、失败、去重、耗时及连接排错 |

AI 首先读 workflow，遇到模糊要求再读 goals：速度优先考虑实际可用的硬件编码器；压缩率优先考虑兼容的 H.265/AV1；画质优先保留源特征并调整质量控制；硬体积限制用码率预算，不能把输出上限当作完整文件压缩。明确用户要求优先，目标冲突时问关键取舍；不会因为“更小”自行降分辨率、删轨道或覆盖原文件。

指南在 `resources/mcp-skills/<id>/SKILL.md`，嵌入程序且原文随安装包发布。还可使用 `muxivra://skills/catalog`、`muxivra://skills/<id>`、`muxivra://reference/parameters`、`muxivra://system/hardware` 资源及 `muxivra_workflow` prompt。读取遵守查询权限。参数参考来自共享定义，专用选项来自当前 FFmpeg 帮助，执行任务无需实时检索网络资料。

读取到设备型号、编码器列表或 available 硬件字段不表示硬件编码已验证；not-tested 保留真实状态。必要试编码须在用户授权处理范围内进行，仅请求计划或连接时不启动任务。任务执行以真实结果核验。

## 权限与生命周期

输入始终手动添加，默认输出范围仅为当前安装目录 outputs 及其子目录；其他输出需另行授权。不会依据自然语言自动扩大目录。父目录须已存在，不支持网络/UNC 路径，解析真实路径并检查符号链接边界。get_job 可核对输出记录；再次 inspect_media 输出时，该路径须另在手动授权媒体目录内。

任务保留最近 1000 条已结束记录，未完成项保留；删除历史保留媒体。requestKey 去重覆盖仍保留的完整批次，部分历史删除或过期时旧键被拒绝，任务不存在不代表没有执行过。

关闭主窗口后托盘服务继续，退出应用后停止。断开 MCP 不取消任务，重连应查询既有 ID，不能因等待响应而重复提交或操作其他任务。

## 设置草稿

未保存的主题、并发数、端口、启用状态、目录、权限和凭据以另一种颜色标记。离开设置时选择“应用并离开”“放弃更改”或“继续编辑”。应用期间显示动画并锁定弹窗，失败保留草稿和原服务，不跳转。硬件详情属于设置子页，返回时保留草稿。保存成功才修改服务与界面主题。

## 诊断

- 401：凭据缺失或不一致；检查客户端实际使用的凭据，环境变量更改不会自动进入已运行进程。
- 403：Host/Origin 或本机访问条件不满足。
- 406：检查 Accept 请求头。
- 路径未授权：在应用手动检查输入目录或额外输出目录。
- 端口占用：更改端口并保存，将新连接信息发送给 AI。
- 服务未运行：检查应用、启用状态和设置页错误。
- 编码失败：查看任务完整日志；编码器存在不代表设备和驱动可用。
