# 媒体项目

字幕编辑和 ASR 工作台共用独立媒体项目。单文件、批量转码继续使用原来的输入和输出流程；字幕工程可将媒体与当前字幕转入单文件处理。

## 创建与管理

创建统一在“项目管理 → 新建项目”二级页完成。选择源媒体，可设置显示名称、可选初始 SRT/ASS/SSA 字幕、字幕画面尺寸（视频尺寸、初始字幕设置或自定义）、默认格式与创建后打开位置。所有内容初始化完成后才发布项目。字幕编辑和 ASR 工作台只打开、关闭已有项目，不在这两个页面创建或删除整个媒体项目；字幕编辑页可管理项目内的 ASS 文件。默认复制媒体并保留原文件；“导入后删除原文件”每次默认不勾选。复制显示进度并支持取消，完成后校验副本、创建 ASS 与项目记录，再执行用户选择的原文件删除。取消、复制失败或源文件在复制期间变化时保留原文件。原文件因权限或锁定无法删除时，项目保留，应用显示“原文件未删除”的原因。

项目位于**安装目录的 `projects` 文件夹**。文件夹使用媒体文件名去除扩展名后的名称，同名自动添加 ` (2)`、` (3)` 等序号。例如：

```text
projects/
  演示/
    演示.mp4
    演示.ass
    project.json
    subtitle-session.json
    subtitle-backups/
    imports/
    player-subtitles/
    asr/results/
    asr/cache/
    logs/
    job-history/
    exports/
  演示 (2)/
  .trash/
```

备份、导入字幕的原始副本、预览字幕、识别结果/原始输出、任务日志和默认导出均属于该项目。临时识别 WAV 在完成或取消后清理。模型与推理运行包属于共享应用依赖，不为每个项目重复复制。应用配置、活动项目指针和统一任务索引仍保存在用户配置目录。

项目管理支持搜索、打开字幕编辑或 ASR、修改显示名称、定位文件、删除到回收站及恢复。“项目文件”二级页集中提供导入字幕、复制工程、字幕与视频导出。显示名称的修改不移动文件夹，以保持任务和媒体路径稳定。恢复时若原文件夹名称已被占用，停止恢复并提示原因。“复制工程”将媒体和当前编辑内容复制为新项目，也可用于保留外部修改冲突中的恢复稿。

删除项目前须完成或取消关联任务。播放器先释放文件，再移动整个项目到应用回收站；原始媒体不受影响。删除失败保留原项目状态，回收站中的完整项目可恢复。应用更新和卸载只处理安装清单内的程序文件，保留 `projects` 和 `outputs`；长期备份请另外复制项目文件夹。

旧版源媒体目录中的工程与恢复会话**不自动打开、适配或迁移**，原文件保持原样。新工程必须在项目管理导入媒体后创建；SRT、ASS、SSA 内容可以在创建时指定，或通过项目文件页导入。

## 保存与工作区

0.25.0 起，同一媒体项目可以包含多个 ASS 字幕文件。创建项目仍自动生成第一个同名 ASS。在字幕列表顶部按文件名称选择当前字幕，右侧按钮可重命名、新建或删除当前文件；新建重名自动添加 `(2)`、`(3)`，重命名不覆盖同名文件。项目始终至少保留一个 ASS，界面和主进程均校验。删除仅影响所选 ASS，其他字幕和媒体保留。创建新文件后，可在项目文件页向当前 ASS 导入现有字幕。

新建 ASS 继承当前字幕的脚本画面尺寸与样式设置，但条目为空，并使用独立文件身份。切换前保存当前稿件，各文件有独立的恢复会话和备份，当前文件选择写入项目清单，重启后恢复。编辑器为各文件分别保留本次打开期间的撤销、重做与选择状态。切换字幕或进入“预览”“样式与脚本设置”不重新载入媒体，因此播放位置保持。旧版本只有一个 ASS 的托管项目按同一个文件继续打开；不扫描或迁移源媒体目录中的旧工程。

“预览”进入二级页，以连续列表显示当前 ASS 的全部条目，支持全文搜索、显示 ASS 标签和包含/隐藏注释；不受编辑页 50 条分页影响。它用于文本与时间整体核查，实际排版效果仍查看视频预览。文本区的图标工具可作用于选区；未选中文字时，粗体、斜体、下划线、删除线、颜色、字号及清除格式作用于整条字幕。换行和样式重置在光标处插入，对齐应用于整条字幕。SRT 编辑模式保留限制，ASS 原内容不因导出而改变。

关闭工程先保存当前编辑稿再释放播放器，重新打开保留已保存内容；关闭不删除任何文件。删除后清除活动工程与编辑状态，不恢复旧空工作区缓存。过期编辑缓存不会写入或重建已关闭、删除或切换的项目，隐藏的编辑页也不会覆盖项目文件页导入的新内容。

ASS 保存完整编辑内容。手动保存与每 60 秒的自动保存更新项目内 ASS，编辑恢复缓存独立保存；每次改变 ASS 前备份原内容，最多保留最近 20 份。工程在应用外被修改时拒绝覆盖，可复制工程保存自己的恢复稿。项目恢复路径须属于该项目，不接受指向外部目录的恢复文件。

字幕编辑工作区固定在窗口内，整体页面不滚动。预览、字幕条目和事件编辑区各自滚动。工程工具在无项目时展开，导入后自动收起到右侧编辑区下方，可随时手动展开；展开后向上显示全宽悬浮面板，工作区大小与位置保持不变；收起状态不遮挡字幕条目或事件属性。视频画面两侧的填充在明暗主题下均为黑色。

## 导出

字幕源文件和简易视频导出的入口为“项目管理 → 项目文件”。字幕编辑页底部的“单文件处理”可将当前媒体与字幕送入 Media 工作流，进行更完整的参数调整。

- **字幕文件**：ASS、SSA、SRT。SRT/SSA 导出会提示格式降级或时间精度差异，内部 ASS 内容保留。默认保存到项目的 `exports`，也可选择其他位置。
- **烧录视频**：使用 FFmpeg 的字幕滤镜，保留 ASS 样式并重新编码画面。可选择 MP4/MKV、软件或硬件视频编码器、质量、速度，以及复制音轨或 AAC。烧录字幕无法单独关闭。
- **字幕轨道封装**：复制兼容的原视频；MKV 使用 ASS 轨道保留样式，MP4 使用 `mov_text` 文本字幕，不能保留完整 ASS 样式或复杂效果。播放时可切换字幕轨道。

视频导出进入统一任务页，可暂停、取消并查看完整日志。提交时创建独立字幕快照，后续工程编辑不会改变排队任务的字幕内容；现有视频和字幕文件不覆盖。不兼容的复制编码会在提交前提示，用户可改用 MKV 或 AAC。

## 从字幕编辑转到单文件处理

点击“单文件处理”先保存当前编辑稿，再在项目 exports 下创建独立 ASS 快照，自动切换到单文件页。默认选择 MKV、复制视频与音频、不保留源文件中的旧字幕轨道，并自动附加编辑后的 ASS；可在“字幕”卡片切换为烧录或选择保留源字幕。默认输出仍位于项目 exports，进入统一任务页后保留项目关联。

选择烧录时，复制视频会自动改为 H.264 软件编码，之后可在输出配置中选择其他编码器、质量或滤镜。选择 MP4/MOV 字幕封装会降级为文本字幕，处理计划提示 ASS 样式损失；MKV 可保留 ASS 样式。输出重名自动编号，源媒体和工程 ASS 不覆盖。后续工程编辑不会改变已转入的快照；需要更新字幕时再次从字幕编辑页转入。此操作不会立即转码，仍须检查计划后开始处理。
