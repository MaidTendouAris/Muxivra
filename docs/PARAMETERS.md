# 参数与预设

0.3.0 参考 [FFmpegFreeUI](https://github.com/Lake1059/FFmpegFreeUI/tree/65aec1ff4dcd62a54c4361fe1719520378750c36) 的参数分类及预设数据定义，按 FFmpeg 的业务语义独立实现。参数映射核对 [FFmpeg 选项](https://ffmpeg.org/ffmpeg.html)、[滤镜文档](https://ffmpeg.org/ffmpeg-filters.html) 和 [x265 参数](https://x265.readthedocs.io/en/master/cli.html)。没有执行或集成 3FUI 程序。

## 页面组织

主面板编辑预设、容器、重名策略、编码器、质量控制和质量值/码率、最高高度、帧率、音频码率。单文件、批量共享参数和批量单项覆盖都可打开同一个“详细参数”编辑器。详细编辑器先修改草稿，“应用参数”才提交；取消保留原配置。

| 类别 | GUI 中的设置 |
| --- | --- |
| 输出与剪辑 | 开始/结束时间、精确/快速定位、时长上限、文件大小上限、faststart |
| 解码 | 硬件解码、CPU 线程、输出格式、设备编号、指定解码器、探测大小/时长、自动旋转 |
| 视频编码 | 完整引擎编码器列表、preset、profile、tune、level、线程、GPU、GOP、B 帧、参考帧、最小关键帧间隔 |
| 质量与码率 | 自动/CRF/CQ/QP/目标码率/专用参数，基础/最低/最高码率、缓冲区、qmin/qmax/qcomp、global_quality |
| 色彩与画面 | 指定宽高或单边比例缩放、适配、缩放算法、像素格式、矩阵/色域/传输特性/范围、写元数据或像素转换、帧率模式 |
| 视频滤镜 | 裁剪、填充、缩放、画面比例、抽帧、插帧、帧混合、色彩转换、HDR 色调映射、调色、降噪、锐化、胶片颗粒、去色带、模糊、扫描/反交错/反胶片、旋转/镜像 |
| 音频 | 引擎编码器列表、码率、质量、采样率、声道、采样格式/位深、压缩等级 |
| 音频滤镜 | 音量、响度标准化、动态响度、重采样、格式、倍速、延迟、高低通、均衡、降噪、压缩、限幅、淡入淡出 |
| 图像输出 | PNG/JPEG/WebP 单帧，GIF/动画 WebP，帧数限制、质量、循环 |
| 流与元数据 | 主页面选择输入轨道，保留/移除字幕、章节与元数据，MKV 附件复制，写入自定义元数据，音轨延迟，内嵌/外部 SRT/ASS/SSA 烧录与字体、字号、描边、阴影、粗斜体、对齐、边距、字距和颜色 |
| 编码器专用参数 | 从真实引擎读取 AVOptions；x264/x265 内部质量与编码参数以 GUI 字段编辑 |

支持 MP4、MKV、MOV、WebM、AVI、TS、M4A、MP3、WAV、FLAC、OGG、Opus、SRT、PNG、JPEG、WebP 和 GIF。PNG/JPEG 输出单张图片；当前不生成图片序列。位深通常需要同时选择对应的编码器与采样/像素格式，例如 PCM 24 位或 yuv420p10le。

## 引擎能力与参数应用

编码器类型来自 `ffmpeg -encoders`，组件参数来自固定形式的 `ffmpeg -h encoder=名称` / `-h filter=名称`，按引擎标识缓存。枚举、类型、默认值和数值范围用于 GUI 与提交前检查；帮助中的同义别名合并为一个控件。滤镜可添加多次、停用、删除、调整顺序，所有指定值参与处理计划。

复制轨道不能应用重编码/滤镜设置。缺少组件、参数越界、无对应输出流、无效裁剪区间、质量控制与编码器不匹配等会明确报错。最终处理计划显示完整参数；每项任务保存参数和引擎快照。剪辑进度按计划输出时长估算。

可用滤镜受实际 FFmpeg 构建影响。例如 libplacebo 需要包含该组件的构建；硬件解码、编码和 GPU 滤镜还需要可用的设备与驱动。仅软件滤镜和本机已有环境经过真实输出验证，不能由“引擎列出组件”推断所有硬件都能执行。

按本次确认的范围，不接入 NVIDIA FRUC DLL、VapourSynth/AviSynth、外部神经网络模型或超分着色器。界面不接收任意完整命令、额外输入/输出地址或任意滤镜图；文件访问类 AVOptions 和不受约束的编码器字典不直接透传。x264/x265 内部参数使用单独的已定义字段。多输入混流、跨文件拼接、两遍编码、多输出流分别使用整套编码配置、外部章节/新附件编辑不在当前参数编辑器范围。

## 预设

“预设”页面提供新建、编辑名称/备注/完整参数、复制、删除、搜索、选择导出及导入。单文件可将当前参数保存为预设；预设可用于单文件、批量共享或单项覆盖。内置预设可复制为个人预设，不能覆盖。

文件格式为 UTF-8 JSON：

```json
{
  "format": "muxivra-presets",
  "version": 1,
  "presets": [
    { "id": "custom-example", "name": "示例", "description": "", "options": {} }
  ]
}
```

上面的 `options` 是结构示意，实际文件必须包含完整必填处理选项。导出文件保留高级参数、滤镜顺序与参数、内部编码参数和元数据；不保存输入/输出目录、当前输入轨道索引或当前预设引用。

导入先验证完整文件和每个参数，再一次性保存。无效格式、版本或参数不会部分导入。每个导入项获得新的个人预设 ID，同名项保留原预设；导出不覆盖已有文件。单次文件上限 2 MB、200 个预设，总个人预设上限 500。旧版本预设仍可读取。

外部字幕路径是可选文件引用；JSON 不嵌入字幕内容。换机器或重新启动后，在详细参数中重新选择该字幕以取得 GUI 文件授权；MCP 使用授权输入目录。3FUI 预设格式按本次确认不提供互导。
