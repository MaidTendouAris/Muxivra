# 0.20.0 验收记录

日期：2026-10-16。Windows x64，Electron 44.5.1，内置 mpv v0.41.0-1087-ge470f8986。本版打通字幕编辑与单文件处理，增加波形纵轴缩放、紧凑字幕条目和播放器悬浮设置。既有 ASR 下载、Python 发现及模型验证见 [0.19.0](history/VERIFICATION-0.19.0.md) 和 [0.18.0](history/VERIFICATION-0.18.0.md)。

## 字幕转入 Media

- 字幕编辑页底部提供“单文件处理”入口。先保存当前编辑，再生成独立 ASS 快照；同时转入项目媒体、字幕、输出目录和默认参数。默认 MKV，复制视频与音频，排除源媒体中的旧字幕，重名自动编号。
- 桌面实际编辑字幕，点击转入、检查处理计划并开始处理，任务完成后 FFprobe 确认输出包含 ASS 轨道，任务保留 projectId。切换烧录自动启用 H.264 软件编码，处理计划通过。单文件页也可手动选择字幕、移除字幕，或保留源字幕轨道。带内嵌字幕的真实源文件验证勾选与“保留/不保留”开关联动，并验证替换单文件页原有媒体。
- 真实 FFmpeg 集成验证 MKV ASS 封装、MP4 mov_text 降级及样式提示、烧录画面。后续修改工程不会改变转入的快照；原始媒体和项目媒体逐字节保持不变。保留 MP4 内嵌字幕并附加 ASS 的实际 MKV 输出有两条有效字幕；PGS 等图像字幕继续使用复制编码，外部 ASS 编码仅应用于新轨道。过期工程和已关闭工程不能转入。

## 波形与字幕条目

- 纵轴显示增益 ×0.25–×64，按钮及 Ctrl＋Shift＋滚轮可调整，横轴 Ctrl＋滚轮保持原行为。重置恢复 15 秒与 ×1。纵轴缩放不触发音频重采样，不改变源文件和播放音量。
- 使用 48 kHz、振幅 0.008 的真实低音量音频，在相同时间视窗读取画布，纵轴 ×32 后波形可见高度从中心线增加到 15 个物理像素；实际播放音量保持 50%。
- 条目约 33 CSS 像素高，开始/结束时间同一行；长字幕预览省略，编辑文本保持完整。1040×720、1440×900、1920×1080 窗口均无横向溢出或整体页面滚动。
- 既有波形 48 kHz 解码、15 秒视窗、横轴缩放、点击定位、平滑游标、倍速、暂停校准、多对白跟随、分页及明暗主题回归通过。

## 悬浮播放器设置

- 控制栏最右侧按钮打开悬浮面板。跳转、逐帧、循环、A–B、音轨/字幕及延迟、外部轨道与播放列表继续可用。窗口范围内定位，内容过高时内部滚动。
- 1040×720 到 2560×1440 的桌面布局检查确认展开不改变预览、列表和编辑区域几何尺寸，搜索、SRT 提示、样式页返回、工程栏悬浮保持可用。窄窗口工程栏使用两行和图标操作。
- Win32 原生区域检查确认视频在面板覆盖范围被裁剪，面板外仍显示视频。强制内部滚动夹具读取实际屏幕视频像素，全屏原生窗口命中范围及退出后位置/暂停状态保持正常。
- Esc 先关闭内部下拉框，再关闭播放器设置；不会误收起工程栏或退出全屏。
