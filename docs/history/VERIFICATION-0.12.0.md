## 桌面与打包检查

实际窗口使用隔离的 .test-data 配置和临时媒体；不读取、修改用户的字幕、媒体或常规配置。最终报告位于 artifacts/qa，截图同时保留明暗主题及最小窗口。

本版重点复验播放器、字幕工程和通用界面；其他功能的已完成验收见 [0.11.0 历史记录](history/VERIFICATION-0.11.0.md)。

- 播放器：快速滚动期间原生窗口隐藏，停止后与 DOM 对齐；窗口及祖先裁剪，播放时间和暂停状态不受滚动影响。常规播放、轨道、循环、截图、全屏及音频仍复验。
- 字幕：1040×720 与 1440×900 两列同屏，首条完整可见、表体不少于 100px；工程栏置底并保留间隔；展开播放或搜索设置只在卡片内滚动。样式页返回保留非零播放位置、暂停状态及播放列表；新增按钮聚焦后的空格、Q/E 和文字输入豁免。
- 字幕全屏：实际 Win32 命中区域覆盖预览卡以外的全屏区域，后台卡片滚动不隐藏全屏视频；退出后恢复小预览，播放位置与暂停状态保持。
- 安全删除：确认取消保留文件，确认执行有加载动画，旧 ASS 禁删，源文件摘要保持，重启后工程不重新生成。
- 原有 ASS 流程：真实 60 秒自动保存、20 份备份、外部冲突/另存与退出恢复、SRT 降级确认、SSA 输入输出、一万条字幕分页继续复验。

最终打包副本 `release/final-0.12.0/win-unpacked/Muxivra.exe` 的播放器、字幕工程、字幕布局、字幕全屏、通用界面、桌面流程与 MCP 交互七组检查全部通过，错误列表为空。结果保存在 `artifacts/qa/packaged-*-smoke.json`。

0.12.0 NSIS 安装包已生成，包内容检查通过：版本正确、7 份离线指南、硬件 Worker、原生模块、许可和固定 SHA-256 的 mpv 均保留，没有 FFmpeg/ffprobe 命令行处理引擎。Electron 必需播放 DLL 保留。本次直接检查打包程序，未重新执行 NSIS 安装/卸载。

## 范围与限制

滚动期间原生视频短暂隐藏，停止约 120ms 后恢复；此策略避免 Chromium 滚动与 Win32 子窗口定位不同步，不重新加载或定位媒体。样式页隐藏工作区会暂停播放，返回保留当前位置。无从确认来源的历史 ASS 不能作为临时工程删除；历史备份不随删除清理。

字幕首轮仍是 ASS 工程、基础样式与高效条目编辑。精细打轴、频谱、关键帧/VFR、可视化排版仍在后续范围。完整兼容性与许可限制见历史验收和 [发行文档](DISTRIBUTION.md)。测试不代表所有媒体、驱动与设备兼容。
