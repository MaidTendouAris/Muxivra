# 0.29.0 验收记录

日期：2026-10-25，Windows x64。上一版见 [0.28.0](VERIFICATION-0.28.0.md)。操作说明见[资源管理](../RESOURCES.md)。

## 本轮交付

- 资源管理拆分主页 / ASR / 环境。主页管理 FFmpeg 与资源概览；ASR 负责模型文件和识别配置；环境页直接展示 Python / PyTorch / CUDA / Transformers 版本、路径、诊断与模型引用。
- 视频、音频与资源管理统一使用标题右侧的横向 Dock，无数字角标和底部占位，页面与卡片保留固定工作区规则。
- 文件下载 / 导入与环境配置分离。模型文件可以在 Python 未配置时导入并暂存，未完成绑定不会出现在工作台。Python、uv 与目标模型的完整离线 wheel 依赖独立准备，清单记录版本、大小与 SHA-256。
- 环境配置使用本地文件和 --offline / --no-index / --find-links，创建隔离环境并执行依赖和 GPU 检查后启用模型。相同 wheel 与 uv 缓存内容可硬链接复用，Qwen / MOSS 的逻辑环境保持分离。
- ASR 工作台只选择可用模型、当前项目音轨与区间。提交时读取最新保存配置，修复资源页保存后立即切页提交可能使用旧快照参数的时序问题。
- 新下载 FFmpeg 默认位于安装目录 engines/ffmpeg。ASR 受管资源与缓存仍位于安装目录，不将大型资源回退至 C 盘用户目录。
- 安装器提供默认不勾选的全新安装，明确提示永久删除范围并二次确认。先完成旧版卸载，再清理已验证安装目录和当前用户专属 AppData；静默安装 / 自动更新使用保留数据路径。
