# 0.26.0 验收记录

日期：2026-10-20，Windows x64。旧版本记录见 [0.25.0](VERIFICATION-0.25.0.md)。开发优先级、八项功能的操作入口和限制见 [字幕实施记录](../SUBTITLE-IMPLEMENTATION.md)。

## 本轮交付

- 原子多选修改；表格排序、移动、交换及可配置列/面板。
- 独立 Worker 的正则/多字段/条件搜索，逐项和全部替换，可取消与超时保护。
- 静态 ASS 安全拆分，多种时间分配；帧前后复制拆分，连接、相同字幕合并、DVD 片段重组、重叠区间展开和字段 Paste Over。
- 波形跟随实际音轨，项目持久缓存。
- 真实视频 PTS/VFR 帧索引、帧单位编辑、关键帧跳转，显示进度并允许取消。
- 可持久化及导入导出的全局样式库，ASS 高亮、补全和局部标签。
- 可保存的 CPS、行长、行数、时长阈值及完整时间顺序重叠质检。

## 验证范围

- TypeScript 和生产构建通过。完整单元 32 文件、226 项通过。
- 项目、字幕媒体导出、双音轨/VFR 分析、波形与快捷键：5 文件、13 项集成测试通过。双音轨和 VFR 使用 FFmpeg 生成的真实媒体，断言实际音频数值、非等间隔 PTS 与关键帧。
- Electron 多 ASS 文件及语言切换、播放跟随与平滑波形、MCP 当前字幕编辑回归通过。
- 0.26.0 打包版字幕工具与 Sub → Media 真实 MKV 封装通过；工具测试包含真实搜索 Worker、复杂正则取消与恢复、输入法组合态、原子撤销、列持久化、帧编辑、原生音轨切换、样式库以及重启恢复。
- 1040×720、1440×900、1920×1080 回归无整页滚动和横向溢出，列表保留可见内容，悬浮工程栏及播放器设置未挤压列表。
- 以上为本轮相关回归，不将真实 ASR 模型推理或全部历史测试组合计为本轮重测。
