# 0.15.1 验收记录

日期：2026-10-14。Windows x64，Electron 44.5.1，内置 mpv v0.41.0-1087-ge470f8986。

本版修复项目卡片长名称溢出，增加导航分类分隔，恢复字幕编辑页的固定工作区。独立项目及字幕视频导出相关验证见 [0.15.0 历史记录](VERIFICATION-0.15.0.md)，真实 Whisper large-v3 模型验证见 [0.14.2 历史记录](VERIFICATION-0.14.2.md)。

## 验证范围

- 类型检查和 main/preload/renderer 编译通过；19 个文件、148 项单元测试通过。
- 项目卡片在 1040×720、1920×1080、2560×1440 下使用长项目名和媒体名验证：标题省略显示，名称、已打开标记、大小、日期和按钮均限制在卡片内，页面无横向溢出。
- Media、Sub 使用独立背景与边框，公共功能区由分隔线区分；导航顺序保持不变。
- 字幕页在 1040×720、1440×900、1920×1080、2560×1440 下整体不滚动；预览设置、字幕表格及事件属性各自滚动。默认收起的工程栏全部位于右列下方，未覆盖左侧条目。展开时占用全宽底行，列表与编辑区同步让出空间。
- 搜索、SRT 模式说明和样式二级页使用内部滚动。由样式页返回后，媒体路径、播放位置保持不变。
- 在最小窗口中，收起状态下字幕表格可用高度约 173px；1920×1080 下约 352px，2560×1440 下约 532px。16:9 预览按剩余高度调整，音量条保持至少 175px。
- 实际原生画面像素验证：预览卡片滚动时画面可见，全屏不受预览卡片裁剪，后台卡片滚动不遮挡全屏画面，退出全屏恢复自适应尺寸并保持定位和暂停状态。
- 项目工作流验证：导入副本摘要一致、默认保留原文件、显式选择后删除原文件、字幕保存、MP4 字幕轨道封装、项目重命名、移入回收站与恢复、再次编辑。测试使用隔离配置与生成的媒体。

报告位于 `artifacts/qa/projects-smoke.json`、`subtitle-layout-smoke.json`、`subtitle-fullscreen-smoke.json`。打包版项目工作流、四种尺寸布局与原生播放器复验均通过，页面错误列表为空；对应报告使用 `packaged-` 前缀。

## 分发包

本地安装包：`release/final-0.15.1/Muxivra-0.15.1-win-x64-setup.exe`。安装包版本、文件名、大小、SHA-512 与 blockmap 验证通过，更新元数据指向配置的 GitHub 仓库。包含 mpv、原生模块、MCP 指南和许可证，不包含 FFmpeg/ffprobe 处理引擎、ASR 运行包或模型权重。

本轮未更改项目存储、转码或模型推理逻辑；常规集成和真实模型精度结果参见对应历史验收。未安装/卸载用户应用，未发布 GitHub Release。
