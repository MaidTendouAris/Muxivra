# 0.17.0 验收记录

日期：2026-10-14。Windows x64，Electron 44.5.1，内置 mpv v0.41.0-1087-ge470f8986。

本版修复删除项目后持续报错、无法切换页面或创建项目的问题，集中项目创建和文件管理，并将设置底部更新区域改为软件信息。此前波形与字幕同步的验收见 [0.16.0](history/VERIFICATION-0.16.0.md)。

## 项目生命周期与安全

- 空工作区不再恢复旧缓存或启动自动保存；删除、关闭和切换后，过期编辑缓存不写入其他工程，也不重建已删除项目。
- 当前项目的打开、关闭、删除、缓存和保存串行执行；真实路径变化、ASS 外部修改及保存失败仍拒绝覆盖。
- 历史空缓存夹具验证删除后所有导航、重新创建、关闭保存与打开重载，页面错误列表为空。
- 管理页导入字幕后返回编辑页能载入新内容；隐藏编辑器在退出时不会覆盖该内容，重启后仍正确保留。
- 项目文件页跟随活动项目，切换后不继续展示旧项目文件。复制工程可保留恢复稿，外部修改的 ASS 字节保持不变。

## 项目工作流与界面

- “项目管理 → 新建项目”二级页集中选择媒体、可选初始 SRT/ASS/SSA、名称、字幕画面尺寸、默认格式和创建后打开位置。“导入后删除原文件”仍默认关闭，副本校验和全部初始化成功后才执行。
- 自定义尺寸、初始毫秒时间、格式和媒体/字幕副本通过真实 FFmpeg 与项目集成验证；缺少必要配置时保留原媒体，不发布项目。
- “项目文件”二级页提供字幕导入、复制工程、字幕导出、视频烧录和字幕轨道封装；视频提交统一任务队列。
- 字幕编辑只打开、关闭已有项目并编辑保存，ASR 只识别已有项目内媒体；模型和识别结果操作仍在 ASR 工作台。
- 项目创建、保存、删除恢复、长名称排版、源文件默认保留及显式删除、字幕导出、视频封装通过桌面夹具。
- ASR 协议夹具验证初稿追加/替换、撤销重做、ASS/SRT 导出、任务暂停/继续/取消和识别记录删除。
- 四种窗口尺寸验证固定字幕工作区、悬浮工程栏及内部滚动；波形、播放同步、明暗主题和原生画面像素检查通过。

## 软件信息与更新

- 设置底部显示版本、应用 GPL-3.0-only、实际 FFmpeg 构建许可和内置 mpv 许可。FFmpeg 许可由已验证引擎编译标志确定，不统一假设所有构建使用 GPL。
- 仓库、问题反馈和手动更新分别指向固定 GitHub 仓库、Issues 和 Releases；测试截获外部打开请求并核对 URL，不打开浏览器。
- 启动自动检查默认开启，开关修改换色并支持离页应用或放弃。关闭后重启不发起自动检查，手动检查仍可用。
- 安全更新夹具验证检查/下载动画、失败重试、明暗主题及最小窗口、自绘重启确认、未保存设置处理、更新前字幕保存和安装启动失败。未下载真实更新或执行安装。
