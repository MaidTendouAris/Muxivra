# 0.27.1 验收记录

日期：2026-10-24，Windows x64。上一版记录见 [0.27.0](VERIFICATION-0.27.0.md)。操作说明见[源码编辑器](../SOURCE-EDITOR.md)。

## 本轮交付

- 源码编辑器新增自动保存开关，默认开启；关闭后保留手动保存和 Ctrl+S，未保存文本不会写入正式文件或同步主应用。开关跨窗口同步并持久保存。
- 新增可收起的项目资源管理器，支持目录树、文件图标、当前文件高亮、刷新、键盘导航与 Ctrl+B。
- 在同一窗口切换项目内字幕文件，主应用同步选择对应的已登记 ASS；保留各文件的视图和撤销历史。
- 手动模式下切换、关闭未保存文件时，提供保存、不保存、取消。原生标题栏关闭和脚本关闭均受保护；取消保存确认会立即中止应用退出。
- 目录按需展开，单次最多枚举 500 项；轮询不重叠。路径解析拒绝逃逸、符号链接、junction、硬链接；过大文件和二进制文件不作为文本打开。
- 源码保存与恢复草稿操作绑定预期文件路径，切换后迟到的请求不能修改新文件或其草稿。
