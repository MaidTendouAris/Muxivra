# 0.28.0 验收记录

日期：2026-10-24，Windows x64。上一版记录见 [0.27.1](VERIFICATION-0.27.1.md)。使用说明见[视频 / 音频工作台](../MEDIA-WORKFLOWS.md)。

## 本轮交付

- 单文件拆分为独立视频、音频处理页。底部横向悬浮 Dock 分别提供 9 / 7 个配置步骤；未选文件时禁用后续步骤。切换步骤保留播放位置，参数与文件状态相互独立。
- 本地 MediaInfoLib 26.05（mediainfo.js 0.3.8）后台线程读取完整媒体信息，优先展示有用字段；支持轨道切换、全部原始字段和搜索。
- 交付页提供完整参数入口和可编辑 FFmpeg 命令。主进程校验后由共享队列执行编辑后的参数；重试保留修改，时间区间修改同步更新预计时长，实际临时输出参数保存在日志中。
- 音频页支持 UTF-8 LRC/TXT 导入与多行 lyrics 标签，增益滤镜可配置。字幕编辑仍可保存快照并转入视频处理，切换字幕烧录 / 封装。
- 视频、音频、批量、字幕编辑、ASR 页面固定窗口高度，仅卡片内部滚动。
- ASR 删除顶部初稿横栏，任务队列入口迁入缩短的识别记录卡片；支持单项及批量删除已结束记录。初稿统一紧凑单行时间 / 文本 / 时长布局。

## 实用限制

- 命令不是系统 shell，参数使用 JSON 双引号；引擎、选定文件、格式 / 协议限制、进度与单个输出受主进程保护。更换文件和封装格式请通过表单；额外文件读写 / 任意 shell 命令不开放。
- MediaInfo 信息完全在本机读取。WASM 本地打包；FFprobe 仍负责 FFmpeg 的轨道索引，两套工具的字段名和轨道编号不混用。
- 歌词为容器标签，播放器显示能力由格式 / 播放器决定。不会把 LRC 标签当作 ASS 字幕轨。
- 许可文件保留上游原始文字，可能含上游行尾空格。未执行 GitHub 发布、安装或覆盖用户现有应用。
