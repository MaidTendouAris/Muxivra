# 0.31.0 验收记录

日期：2026-10-25，Windows x64。上一版见 [0.30.0](history/VERIFICATION-0.30.0.md)。操作说明见[项目与字幕](PROJECTS.md)。

## 本轮变更

- 新建项目页移除静态“项目预处理”说明卡片。实际波形/帧索引预处理、进度反馈与取消流程保留。
- 波形默认滚轮左右平移，不再使用空格拖动；空格恢复播放器行为。原生 mpv 获得焦点时，也会将键盘波形动作转发到当前字幕页；滚轮仅在波形区域处理。波形滚动、横轴缩放、纵轴增益、重置及清除选区共八项操作接入快捷键配置，支持按键或修饰键加滚轮，保存后生效。
- 快捷键页使用双栏紧凑列表；支持滚轮录入、右键清除、冲突提示和恢复默认。旧配置自动补充新操作；新增默认绑定遇到原有自定义按键时保持未绑定，不抢占原按键。
- 字幕文字与四种 ASS 样式颜色全部替换为应用自绘选色器，不使用 input[type=color]。饱和度/明度画布、色相、透明度、HEX/RGB 均为本地草稿；应用只提交一次，取消不修改字幕。文字选区在打开前捕获，应用支持一次撤销。
- 屏幕取色使用 Electron 的 EyeDropper；选色器与遮罩隐藏后启动，返回 sRGB 颜色到草稿，不存储截图，不自动写入字幕。原生视频遮挡处理忽略取色期间隐藏的弹窗。

## 已执行验证

- 单元测试：38 个文件、268 项通过，包含颜色转换、屏幕取色结果与取消、滚轮绑定、旧配置迁移和多语言文案覆盖。
- 屏幕取色真实验证：Electron 安全来源启动工具，等待两帧仍保留用户激活，成功拾取独立窗口的 #1283C7。AbortController 取消正常。独立原生浮层的合成 Escape 未由测试注入器投递，不将其记为原生键盘验证；应用层另有 Escape 取消处理。


- subtitle-color-smoke：最终打包程序 0.31.0 通过 10 组真实项目检查。180 次自绘画布/色相拖动期间，文档与磁盘完全不变；取消不产生副作用。选区文字一次生成 BGR 标签并可一次撤销；屏幕取色可通过应用层 Esc 取消而保留选色器；四种样式颜色和透明度提交/撤销正确。1040 窗口下明暗主题选色器完整显示。无效 RGB 后重新输入相同合法 HEX 会正确恢复 RGB 通道值；该回归同样通过。


- waveform-shortcuts-smoke：6 组通过。真实旧 14 项配置升级、已有自定义组合键冲突保护、双栏几何、按键/Alt 滚轮录入、清除/保存、活动页执行、实际 mpv 命名管道 keypress 经主进程转发到波形、空格恢复播放/暂停、重启保留。
- subtitle-waveform-interaction-smoke：更新后的 11 组通过。默认滚轮移动，空格正常播放；原有选区、边界微调、按选区新增、帧编辑、独立源码窗口及项目重新预处理继续可用，媒体与字幕保持完整。100 RAF 采样 99 次移动，最大单步约 15.6ms。
