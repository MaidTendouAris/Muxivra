# 0.19.0 验收记录

日期：2026-10-15。Windows x64，Electron 44.5.1，内置 mpv v0.41.0-1087-ge470f8986。本版增加应用内官方下载、安装目录模型存储、Python 自动发现与可复制的 AI 环境配置提示词。此前真实模型推理及波形平滑验证见 [0.18.0](history/VERIFICATION-0.18.0.md)。

## 官方下载与模型存储

- 软件内提供 Whisper large-v3、Qwen3-ASR-0.6B/1.7B、Qwen3-ForcedAligner-0.6B、MOSS-Transcribe-Diarize、MiMo-V2.5-ASR 及 MiMo-Audio-Tokenizer。
- 六个 Python 模型资源的固定版本清单通过真实官方 Hugging Face 网络检查；实际下载每个 config.json，大小和 Git blob 哈希均一致。MOSS 聊天模板和分片索引包含在下载列表中。MiMo 音频 Tokenizer 的官方配置没有 model_type，辅助模型导入允许这种合法配置。
- 文件流夹具验证普通文件 Git blob SHA-1、LFS SHA-256、大小与分片索引校验；损坏文件不发布，错误状态可见。下载进度、取消、绑定模型、从绑定模型进入工作台通过桌面检查。
- 模型、辅助模型、Whisper 运行包、下载临时文件和推理缓存都指向安装目录下的 asr；用户配置目录只保存轻量配置记录。空间不足或目录不可写时明确失败，不自动转存到 C 盘。
- 本地导入逐文件复制和校验，原件保持不变；已经位于应用 ASR 存储中的模型直接复用。复制取消不发布文件，清理自己创建的临时目录。自定义后端的模型目录包含应用存储时，排除存储目录，避免递归复制。
- 旧模型记录保持原路径，提供手动转存入口；移除记录保留文件。应用内新导入模型自动成为当前选择。
- 使用已缓存的官方 CPU 运行包实际解压、核对 SHA-256 并执行 whisper-cli --help；重新下载到安装目录时替换旧运行包记录，避免相同 ID 重复。旧程序不删除。

官方网络检查报告：artifacts/qa/asr-official-validation.json。本版未重新下载所有大型权重，未重跑完整模型推理；下载文件流与失败路径使用明确标记的小型夹具，实际推理结果独立保留于 0.18.0。

## Python 与 AI 配置

- 打开环境页自动检测，也可手动刷新。覆盖已注册解释器、Python 启动器、PATH、Windows 注册项、用户 Python 安装、Conda 清单和有限目录、应用环境目录，不递归扫描整盘，最多检查 64 个实际解释器。
- 检测以 Python 隔离模式和禁止字节码写入的参数读取版本及依赖元数据，不安装包或加载模型。失败、超时和信息缺失可见。初步依赖匹配不当作最终可用性，保存仍进行适配器与 CUDA 检查。
- 实际发现本机 Python 和已注册 Qwen 环境，通过“使用此 Python”填入路径，完成真实 Qwen 依赖/CUDA 检查，无需文件对话框寻找解释器。
- 在隔离安装目录创建真实 Python 3.12 虚拟环境（不安装依赖），未预先提供其解释器路径，检测仍自动发现并正确返回版本、虚拟环境和目录来源。
- 提示词包含后端、已验证官方依赖、目标环境、模型及缓存路径、探测脚本、实际硬件和检测结果。剪贴板检查确认内容包含对应 Python 路径与缓存设置，不包含 MCP 凭据，不针对某个 AI 客户端。
- 推理进程的 Hugging Face、Torch、CUDA、Triton 等缓存和临时路径指向安装目录，覆盖进程继承的同名缓存设置。AI 安装提示词要求独立环境、不修改其他应用及全局环境变量；MiMo 保留官方 Linux/CUDA 约束。
