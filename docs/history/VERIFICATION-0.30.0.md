# 0.30.0 验收记录

日期：2026-10-25，Windows x64。上一版见 [0.29.0](VERIFICATION-0.29.0.md)。操作说明见[项目与字幕](../PROJECTS.md)。

## 本轮变更

- 移除安装器中的“全新安装”及其个人文件清理脚本与 CI 步骤。常规安装、升级和卸载保留已有项目、模型、环境及用户配置；原有已知程序文件清单、忙文件回滚与旧卸载失败保护保留。
- 创建项目时完成媒体复制与校验、全部音轨波形预处理、视频帧索引，全部成功才发布项目并执行用户选择的源媒体删除。各阶段显示进度、可取消；失败只移除未发布的新项目。
- 以 48 kHz 分析音频，存储 1 ms 基础分箱的有符号峰值/RMS 及 8 倍多级数据；不存储完整 PCM。视频帧索引包含真实 PTS、关键帧及 VFR 信息。所有分析文件保存在项目 analysis 目录。
- 编辑时按需读取分析文件，不启动媒体解码。已有项目可在“项目管理 → 项目文件 → 重新预处理”生成缓存；重建使用暂存和旧缓存回滚，保留媒体、ASS 与项目清单。
- 波形移动到右侧编辑卡片上方，播放器获得原有波形空间。默认 15 秒视窗连续跟随播放，使用带余量的缓冲查询和平滑游标；支持横纵缩放和底部可拖动进度条。
- 左键点击定位、拖动选区、两侧手柄拖动微调、方向键 1ms / Shift 10ms 微调、右键设选区终点、空格拖动平移。存在手动选区时，新增字幕使用该区间。
- 起止与持续帧数整合到时间字段中，保留关键帧定位与当前帧前后拆分。右下角项目管理按钮改为源码编辑，打开当前字幕独立窗口。

## 格式与限制

编辑器的时间为整数毫秒；ASS 保存精度为 10 毫秒。波形选区用于创建字幕时按此精度取整。基础波形分箱为 1 毫秒，纵向缩放只改变显示。真实视频帧索引最多 2,000,000 帧，首次生成速度取决于视频解码；本次 TED 验证大部分时间用于帧索引，后续编辑直接复用。

项目预处理要求可用的 FFmpeg 和足够磁盘空间。每小时每音轨的波形数据约 49 MB。外部临时音轨与非托管媒体保留原有兼容读取路径。原有资源管理、ASR、源编辑器、MCP 和媒体交付功能未变更设计。

本轮未提交或推送 GitHub，未安装或覆盖用户当前应用。
