# 0.27.0 验收记录

日期：2026-10-24，Windows x64。上一版记录见 [0.26.0](VERIFICATION-0.26.0.md)。操作说明见[源码编辑器](../SOURCE-EDITOR.md)、[媒体项目](../PROJECTS.md)和[使用指南](../USAGE.md)。

## 本轮交付

- 独立 Monaco 源码窗口，ASS/SSA/SRT 高亮、段落折叠、行号、查找替换、字体缩放、全文缩略图。
- 停止输入 700ms 后自动保存；项目 ASS 与主编辑器双向同步并进入撤销历史。保持提交的源码、注释与格式；无效 ASS 先保留恢复草稿，不破坏正式工程。
- 内容版本和磁盘哈希共同检查并发修改；冲突时保留缓冲区，支持重新载入或另存副本。关闭窗口及退出应用等待保存；文件缺失或工程关闭后切换只读。
- 新增资源管理页，集中 FFmpeg、ASR 模型、下载/部署与运行环境。ASR 识别参数留在工作台的二级页面。
- 项目管理统一创建、打开、切换、关闭和删除项目；字幕编辑和 ASR 页面不再直接打开或关闭项目。
- 右键点击快捷键绑定即可清空，并退出录入态；仍需保存设置才能生效。
