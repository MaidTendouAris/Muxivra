# 0.22.0 验收记录

日期：2026-10-16。Windows x64、RTX 3060 Laptop 6 GB。本版修正 Qwen/MOSS 长时间显示 0% 的反馈，并新增当前字幕工程的 MCP 编辑。此前模型安装与隔离存储验收见 [0.21.0](history/VERIFICATION-0.21.0.md)。

## ASR 进度

- 原适配器把所有非结束阶段统一映射为 0%。现在加载、音频特征准备、识别、词级对齐分别显示阶段。未知百分比采用动态状态，不伪造分母或剩余时间；耗时每秒更新。
- Qwen 在原生 SDK 的 batch/generate/align 调用外观察真实窗口完成量和解码步。多窗口阶段按已完成音频量显示当前阶段百分比；当前窗口和对齐无可靠分母时显示真实计数与动画。传入 SDK 的音频、参数、上下文、调用顺序和结果保持原样，没有为进度额外切分音频。
- MOSS 使用官方输入与 Token 回调。采样及 Beam 参数保持原样；Beam 大于 1 时不使用官方不支持的 streamer，保留阶段反馈。
- 真实测试用用户指定 TED 视频的选定区间整段提交。Qwen 0.6B＋ForcedAligner：15 秒生成 2 条；MOSS：15 秒生成 3 条。两者任务完成，记录了变化的阶段、计数及未知进度状态，未生成不可靠的剩余时间，每次仅有一个原始结果文件。
- 另复用本机已下载的 Qwen 1.7B 权重，10 秒选定区间整段识别成功，生成 1 条，解码步持续更新，并进入词级对齐。只读取已有权重，环境、缓存和测试工程继续位于 D 盘隔离测试目录。
- 多原生窗口的真实累计计算、百分比与观察器异常恢复由单元夹具验证。本轮短片不需要原生 SDK 多窗口；即时阶段切换可在一次界面推送中合并，持续生成时的计数变化单独校验。
- 报告：artifacts/qa/asr-progress-smoke.json、asr-progress-qwen-1.7-smoke.json。完整处理日志定期保留原生阶段摘要。原有百分比协议仍兼容，新字段为 progressIndeterminate、progressScope、progressMetrics。

## 当前字幕 MCP

- 新增 get_current_subtitle_project、read_current_subtitles、edit_current_subtitles；工具总计 23 个，离线指南总计 8 份，新增 subtitles。
- 使用真实 Streamable HTTP MCP 连接，读取页面最新未自动保存文字，提交翻译、ASS 淡入淡出、完整样式与条目插入；确认 GUI 立即同步、ASS 文件保存，以及整批撤销。
- 结构化操作限制目标为当前字幕主工作区及已打开工程，不能改项目关联路径。编辑需启用查询及独立“编辑当前字幕工程”权限，后者默认关闭。不依赖扩大媒体目录授权。
- revision 绑定内容及随机编辑会话版本，人工修改、撤销、重做、工程切换或重启后旧 revision 失效。主进程预检和渲染器应用前再次核对，避免读/写之间的竞态；离页保存和 AI 修改有互斥保护。
- 实际验证过期版本拒绝、批次末尾非法操作导致整批不应用、重复 requestKey 只保存一次、权限开关保存、离开字幕页及关闭工程后拒绝。模型文本保留为数据，不解释为操作指令。
- AI 修改进入正常撤销历史并保存。保存错误不会谎称成功，编辑器保留可恢复内容，错误明确要求先重新读取状态。
- 报告：artifacts/qa/subtitle-mcp-smoke.json。打包后复测结果为 packaged-subtitle-mcp-smoke.json。
