# 0.10.0 验收记录

日期：2026-10-12。Windows x64，Node.js 22.17.1，Electron 44.5.1，mpv v0.41.0-1087-ge470f8986。

本版增加 MCP 交互页，AI 可申请目录授权和一次性转码，用户在详情页批准或拒绝；已获授权的操作仍可直接执行。增加设置中的快捷键二级编辑页，保存后同步更新界面与原生 mpv。内置指南补充申请、等待、重连和拒绝处理，服务器增至 20 个工具。字幕与 Aegisub 的差距及分阶段改造范围另见 [字幕评估](../SUBTITLE-ROADMAP.md)，待开发功能本次没有实现。

## 边界

预计剩余时间来自实际处理进度；未开始的任务仅在存在匹配历史样本时估算。首帧前、未知时长或没有匹配样本时显示估算中/暂无估算。运行项暂停后仍占用并行名额，等待项可以重新排序。

1000 条上限用于已结束记录，所有未完成项保留。超限时清理最早结束的历史及其日志，媒体保持。删除部分批次后旧去重键拒绝返回不完整批次；整个批次清除后关联不再保留。旧版本没有保存的退出码、事件或实际执行参数不能事后恢复，详情明确标记缺失或显示原计划。

不再采用 CIM AdapterRAM。优先通过 NVIDIA 驱动读取物理总容量，否则采用并标明 DXGI 系统可用容量。共享内存上限不计入物理显存。部分驱动不提供某些性能计数器，此时显示不可用，首个 CPU/GPU 样本需等待采样。硬件信息是采集快照，设置页可更新；软件后端存在不等于驱动或显卡可用。未覆盖所有显卡、驱动、音频设备、容器、HDR 与其他操作系统。

MCP 经官方 SDK 和原始 HTTP JSON-RPC 验证；未更改用户客户端配置。未验证任意大模型接收提示词后的自主操作质量，也未证明任意编码器都适用模糊要求。AI 需本机执行能力；远程 127.0.0.1 不能连接这台电脑，部分客户端仍需重载/重启。指南随应用版本更新，实际 schema、引擎响应和执行结果是支持范围依据。

MCP 申请只覆盖目录授权与转码批次，不能批准任意命令。目录批准为持久授权；转码批准只允许该批次一次，不打开持续提交权限，也不扩展目录范围。单次最多 500 个任务及 256 KB 参数，待审最多 100 条，已结束申请最多 1000 条并受总大小限制；历史移除后去重键也会到期。审批期间意外退出只核对已有持久结果，不重做不确定操作。持有同一有效凭据的客户端共享申请记录。

快捷键保存作用于应用内播放器与字幕编辑，不是系统全局热键。Esc 固定退出全屏/取消录入；Win 组合可能被操作系统占用。字幕仍是基础 SRT 编辑，ASS 样式、精细波形打轴、可视化排版和 Automation 兼容属于评估中的后续范围。

安装包保留 Electron 必需播放 DLL 和 mpv 内部播放库，不包含 FFmpeg/ffprobe 处理引擎。应用源码包不包含上游 mpv 全部静态依赖的对应源码；公开发行安排见 resources/mpv-licenses/SOURCES.md，安装包未签名，供本地试用。
