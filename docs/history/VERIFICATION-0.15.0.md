# 0.15.0 验收记录

日期：2026-10-14。Windows x64，Electron 44.5.1，内置 mpv v0.41.0-1087-ge470f8986。

## 界面与预览

- 项目工作流实际验证媒体复制、默认不勾选删除、显式删除、重命名、视频导出、回收站恢复和再次编辑。
- 导航分组为 Media/Sub，任务与 MCP 位于预设上方。
- 1040×720、1440×900、1920×1080、2560×1440 下保持页面滚动；条目区最小 480px，最小窗口中的表格可用高度约 354px。
- 底部工具栏浮动，无项目时展开，导入后收起，可手动展开。滚动到页面底部后，事件属性不被底栏遮挡。
- 视频两侧填充为黑色，音频信息继续使用对应主题的可读文字。
- 原生视频像素检查确认卡片滚动时保留画面；全屏覆盖完整窗口，后台卡片滚动不隐藏视频，退出后保持定位与暂停状态。
- ASR 工作台使用当前项目，完成整段与兼容分片的预览、ASS/SRT 导出、原始结果、工程追加/替换、撤销/重做、暂停/继续/取消与记录删除；源媒体和工程保留。测试后端用于协议和工作流验证，不代表模型精度。

测试中发现并修复：Windows 下暂停播放器不会释放媒体文件，项目删除前现改为关闭关联播放进程；全屏时页面滚动条会减少固定播放区域宽度，现全屏隐藏该滚动条，退出后恢复页面滚动。

报告：`artifacts/qa/projects-smoke.json`、`asr-smoke.json`、`subtitle-layout-smoke.json`、`subtitle-fullscreen-smoke.json`、`player-smoke.json`。
