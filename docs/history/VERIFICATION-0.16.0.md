# 0.16.0 验收记录

日期：2026-10-14。Windows x64，Electron 44.5.1，内置 mpv v0.41.0-1087-ge470f8986。

本版加入局部音频波形与字幕播放同步，并将展开的工程栏改为悬浮面板。独立项目验证见 [0.15.0](VERIFICATION-0.15.0.md)，固定字幕工作区见 [0.15.1](VERIFICATION-0.15.1.md)，真实 Whisper large-v3 模型结果见 [0.14.2](VERIFICATION-0.14.2.md)。

## 核心与解码

- 类型检查、main/preload/renderer 构建通过；20 个单元测试文件、151 项通过。
- 常规集成：38 项通过、4 项按默认配置跳过，涉及真实 FFmpeg、MCP、项目、ASR 协议和波形；跳过项为大模型与大包下载专项。
- 48 kHz 浮点 PCM 按当前视窗解码，流式聚合正负峰值与 RMS，跨声道保留最大幅度，不再将整片音频降为 2 kHz / 2000 点。缓存仅保留最近的 32 个视窗。
- 真实 8 kHz 信号和反相立体声仍有正确峰值与 RMS；1 秒延迟音轨在起点和 800ms 视窗跳转后均保留正确静音区间。另验证音频尾部补零、无音轨与读取取消。
- 请求时长限制为 250ms 至 120s、输出最多 4096 个像素桶；新请求取消过期解码。关闭应用中止后台读取，删除项目前等待波形进程释放媒体。

## 字幕界面

- 1040×720、1440×900、1920×1080、2560×1440 保持整体页面不滚动，列表、事件编辑区和预览设置独立滚动。
- 工程栏收起时保留右下角位置；展开为全宽悬浮面板，展开前后预览、条目列表、编辑区坐标和尺寸保持不变。SRT 模式与样式二级页面继续可用。
- 跟随播放默认关闭。真实播放/跳转验证自动选中、滚动定位与跨页；重叠对白一起选中，注释排除。编辑输入框期间暂缓，退出输入后恢复，关闭开关后保留手动选择。
- 默认波形视窗 15 秒，Ctrl＋滚轮缩放不会改变页面缩放；点击波形定位 mpv，实际播放越过视窗时自动切换。提供时间刻度、字幕区间、播放游标、相邻范围、缩放/重置按钮和读取反馈。
- 无音轨显示紧凑提示。暂停状态下的主题变化和窗口尺寸变化会重绘波形。
- 原生画面像素验证通过：预览内部滚动仍有画面，全屏脱离卡片裁剪，后台滚动不隐藏全屏，退出后恢复大小并保持定位与暂停状态。

报告：`artifacts/qa/subtitle-audio-smoke.json`、`subtitle-layout-smoke.json`、`subtitle-fullscreen-smoke.json`。打包版报告使用 `packaged-` 前缀。

## 分发

安装包位于 `release/final-0.16.0/Muxivra-0.16.0-win-x64-setup.exe`。发行包的版本、大小、SHA-512、blockmap 与 GitHub 更新配置检查通过。打包版波形交互、字幕同步、明暗主题、四种尺寸布局、项目导入/保存/删除/恢复和原生播放器复验通过，页面错误列表为空。包含 mpv、原生模块、MCP 指南与许可证；不捆绑 FFmpeg/ffprobe 引擎、ASR 运行包或模型权重。

本轮使用生成的媒体和隔离配置验证，不更改用户项目。未运行真实大模型识别、未安装或卸载用户应用、未发布 GitHub Release。

此版提供可缩放波形与时间标记，频谱、拖动字幕起止、选区试听、轨道/声道选择和关键帧/VFR 索引仍属于后续范围。操作说明见 [使用指南](../USAGE.md)，复验命令见 [开发文档](../DEVELOPMENT.md)。
