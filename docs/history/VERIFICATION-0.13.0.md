# 0.13.0 验收记录

日期：2026-10-13。Windows x64，Electron 44.5.1，内置 mpv v0.41.0-1087-ge470f8986。

本版增加 GitHub Releases 应用更新：每次进程启动检查一次，设置页提供手动检查、下载进度、失败重试和重启安装。更新安装前处理设置草稿、保存字幕并停止后台服务；安装程序成功启动后才退出。安装与卸载改用构建时编译的应用文件清单，保留 outputs 和其他用户文件。

## 桌面与打包检查

最终打包副本 `release/final-0.13.0/win-unpacked/Muxivra.exe` 的更新 GUI 和普通桌面流程检查全部通过，错误列表为空。配置、字幕和临时媒体使用隔离目录，不修改用户配置或源媒体。

- 更新 GUI：启动检测、全局新版本提示、手动检查动画、网络/下载失败重试、下载进度与自绘重启确认；取消确认继续运行。
- 数据保存：未保存设置必须应用、放弃或继续编辑；重启前将最新字幕落盘。安装启动失败后确认窗保持锁定，提供重试安装或退出，不能返回已停止的后台服务。
- 布局：明暗主题与 1040×720 最小窗口；更新横幅可见时，字幕预览、条目、编辑及底部工程栏仍在窗口内。
- 原有桌面流程：实际转码、mpv 播放、字幕编辑/导出、任务暂停/恢复/取消/排序、硬件刷新/实时监控、MCP 共享队列及托盘后台运行。
- 包内容：0.13.0 版本、7 份离线指南、硬件 Worker、原生模块、许可和固定 SHA-256 的 mpv 保留；没有 FFmpeg/ffprobe 命令行处理引擎。
- 发行元数据：包内 `app-update.yml` 固定官方 GitHub 仓库且不含发布凭据；`latest.yml` 的版本、文件名、大小和 SHA-512 与最终 NSIS 安装包一致，blockmap 存在。

报告保存在 `artifacts/qa/packaged-app-update-smoke.json`、`packaged-desktop-smoke.json`、`installer-preservation-smoke.json` 和 `package-contents.json`。以前版本的完整验收见 [0.12.0 历史记录](VERIFICATION-0.12.0.md)。

## 范围与限制

此次未通过真实 GitHub Release 执行跨版本升级，未重新安装用户的应用，也未执行 GitHub Actions 发布工作流。仓库检查时尚无公开正式 Release；需要按 [发行文档](../DISTRIBUTION.md) 发布同一次构建的安装包和 `latest.yml` 后，客户端才能获取可用更新。

0.12.0 及更早版本需先手动安装新版。旧版卸载程序会递归删除安装目录；新安装程序检测到旧版非空 outputs 时会停止。首次升级前将 outputs 和安装目录中的其他个人文件移到目录之外，安装后再移回；具体保护规则见 [应用更新](../updates.md)。

自动更新只检查公开正式版本，不自动下载或强制重启。重启会停止运行任务，等待任务保留；测试不代表所有网络、驱动和媒体兼容。代码签名、播放器对应源码及其他发行限制仍见 [发行文档](../DISTRIBUTION.md)。
