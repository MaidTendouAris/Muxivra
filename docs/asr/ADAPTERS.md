# 本地模型适配器与环境

ASR 工作台提供 Whisper、Qwen3-ASR、MOSS-Transcribe-Diarize 和自定义 JSONL 后端。每种权重使用自己的加载器和运行环境；通用的是任务和字幕结果协议。安装包只包含 Muxivra 的 Python 桥接脚本，不附带 Python、PyTorch、模型权重或上游推理源码。

## 配置流程

1. 在项目管理创建或打开媒体项目。
2. 在资源管理的 ASR 页下载或导入完整模型文件，导入不要求先配置 Python。文件复制到安装目录，原件保留。
3. NVIDIA 用户进入环境页，分别准备 Python 和目标模型的完整离线依赖包（Whisper 使用原生运行包），再为目标模型一键配置。Qwen 词级时间还需下载或导入 ForcedAligner。
4. 手动兼容时，在环境页检测本机 Python，注册并检查已有环境。缺少依赖可复制环境配置提示词交由 AI 处理；“保存并检查”只读取依赖版本、CUDA 和设备，不自动安装。模型文件可绑定至已验证的对应环境。
5. 在 ASR 页已配置模型的“配置识别参数”二级页调整语言、设备、精度及后端专属参数，按模型保存。回到工作台只选择可用模型、当前项目音轨和识别区间。


环境支持编辑、重新检查和移除记录；仍绑定模型或未完成任务的环境不能移除。移除模型或环境记录不删除权重、Python 或依赖。缺少依赖的模型仍可在资源页修改配置，工作台只列出可直接使用的模型。

下载、存储和 Python 检测的完整说明见 [模型与环境配置](SETUP.md)。安装目录不可写或磁盘空间不足时明确报错，不转移大文件到 C 盘用户目录。

## 后端与时间

| 后端 | 结果 | 环境要点 |
| --- | --- | --- |
| Qwen3-ASR | 原文；配置 ForcedAligner 并开启词级时间戳后得到时间 | 官方 qwen-asr 0.0.6 固定 Transformers 4.57.6、accelerate 1.12.0；包声明 Python >=3.9，本版实际环境为 3.12 |
| MOSS-Transcribe-Diarize | 原生时间、文本和说话人 | 官方包 0.1.0，Python >=3.10、Transformers >=5.6,<6、Torch/torchaudio >=2.8；模型须保留 chat_template.jinja |

Qwen 不开启对齐时，文本成为未打轴 ASS 注释；不会用语速推算出看似精确的时间。对齐器可能去掉连字符、标点或产生零时长词；适配器按规范化字母/数字匹配原文，保留原文标点，把零时长词附在相邻有效词文本中，保留完整原始词时间。整段无法对应时保留未打轴原文，不伪造词边界。字幕分组的字符数和最长时长可调，边界仍来自有效词时间。

MOSS 的语言选项是提示词中的软提示，默认 auto 使用官方原生提示，不保证约束输出语言；原生接口不返回检测语言，应用不会把请求语言当作实际输出语言。MOSS 说话人保存在统一结果的 speaker 字段，工作台展示，并写入 ASS 的角色字段。SRT 无角色或样式字段，导出时只保留文本和有效时间。

模型每次接收整个选定音频区间；应用兼容分片默认关闭。Qwen 官方 SDK 自身对长音频的窗口处理，以及 MOSS 的音频特征分块，仍由其实现决定，不能保证模型内部完全不切分。应用不在失败后自动改成分片。生成 Token 上限、输入上下文上限可能影响结果完整性，资源不足或结果截断时调整参数再运行；失败保留日志，不覆盖工程。

## 可配置选项

识别二级页根据后端提供以下项目；不把一个模型的参数传给另一个模型。

- 按模型保存：语言、CPU/GPU/自动、线程数、兼容分片与时长、无时间戳时的显式估算。音轨和起止区间仅在 ASR 工作台作为每次任务设置。
- Qwen：计算精度、注意力实现、GPU 序号、Transformers/vLLM、最大生成 Token、推理批次、词级时间戳、对齐设备、字幕字符数和时长；vLLM 时另显示显存比例、上下文上限、张量并行数。vLLM/FlashAttention 需用户独立安装，本版实测路径为 Transformers + SDPA。
- MOSS：精度、注意力实现、GPU 序号、输入/生成 Token 上限、采样开关、Temperature、Top P、Top K、重复惩罚、Beam 数、KV 缓存位置、音频编码批次与显存预算。
- Whisper 和自定义协议继续提供 Beam size 与提示词；Qwen 支持上下文提示，MOSS 支持识别指令。

## 自动部署与手动兼容

NVIDIA 用户先在资源管理准备模型文件、Python 与离线依赖，再在环境页按目标模型一键配置。配置过程离线且不会修改系统 Python。CPU、旧显卡和自有环境使用兼容配置，可检测本机 Python 或复制 AI 配置提示词。Qwen 和 MOSS 的 Transformers 主版本不同，逻辑环境分开；同版本文件可通过 uv 缓存硬链接复用。详细版本、存储与校验见 [部署说明](SETUP.md)。

GPU 是否可用由该 Python 环境读取；选择 GPU 时未检测到 CUDA 会明确失败。模型和对齐权重应完整下载到本地，识别过程启用离线模式，不临时下载缺失组件。与手动安装有关的上游包、模型许可由用户选择的发行版本确定。

实际测试方法和限制见 [验收记录](../VERIFICATION.md)。模型可自行更换，识别精度仍由模型及其参数决定。

0.18.0 验收中的 MOSS 全片 CPU 测试在附加 en 提示的配置下将英文音频识别为西班牙语，已保留原生输出。官方默认提示的 15 秒测试输出正常英文；默认提示的全片 GPU 复测因显存不足、速度明显变慢，按用户选择停止。尚不能确定语言提示是偏差原因，也不能将短片成功视为长音频的准确度保证。auto 使用官方默认提示，其他语言仅为软提示，应用不改写模型输出。

0.23.0 起的 Windows SDPA 内存修正、整段上下文缓存和配置说明见 [显存管理](../ASR.md#nvidia-长音频与显存)。默认提示的长音频语言偏差仍属于模型输出限制，不会由内存策略修正。
