# 0.11.0 验收记录

日期：2026-10-12。Windows x64，Node.js 22.17.1，Electron 44.5.1，mpv v0.41.0-1087-ge470f8986。

本版开始字幕重构，统一采用 ASS 编辑工程，支持 SRT/ASS/SSA 输入输出。媒体载入后立即创建同目录同名 ASS，已有则载入；不可写时选择新位置。增加 60 秒工程自动保存、独立恢复缓存、20 份原文备份、外部修改保护、基础样式和条目批量编辑。详细范围见 [字幕改造记录](SUBTITLE-ROADMAP.md)。

## 范围与限制

本轮提供 ASS 文档、工程安全、基础样式与条目编辑。全片波形仍是概览；缩放/拖动打轴、频谱、关键帧/VFR 索引、可视化排版和高级时间处理尚未实现。卡拉 OK、矢量/复杂特效制作、字体附件和人工翻译辅助未列为本轮必交项；不执行 Aegisub Lua/MoonScript 插件。

ASS/SSA 文件时间量化到 10ms；恢复缓存和当前编辑保留原毫秒，重新从 ASS 文件载入时按文件精度恢复。SRT 导出保留文本和时间，移除样式、标签、注释及绘图并提示损失；SSA 有图层和部分样式限制。ASS 语义内容保留不等于逐字节原文往返，原文备份用于恢复。媒体或项目丢失、外部改动时需另存后再导入，不自动覆盖。新文件发布依赖支持硬链接的文件系统；不支持时提示选择位置。

一万条字幕为合成测试数据，仅证明本轮 50 条分页与末页编辑行为；未证明所有大型真实 ASS 或所有渲染器兼容。未覆盖所有硬件、驱动、容器、HDR 与其他操作系统。

任务默认保留 1000 条已结束记录，未完成项不清理；删除记录不删除媒体。旧记录缺失的执行字段无法补回。预计时间取决于实际进度或匹配历史，未知时显示估算中/暂无估算。

MCP 经官方 SDK 和 HTTP 验证，未改用户 AI 客户端配置；AI 需本机连接能力。目录批准为持久授权，一次性转码批准不打开持续提交权限。硬件后端存在不代表显卡或驱动可用，性能字段缺失显示不可用。

安装包未签名，供本地试用。应用源码包不包含上游 mpv 全部静态依赖对应源码；公开发行安排见 `resources/mpv-licenses/SOURCES.md`。
