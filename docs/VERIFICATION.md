- 41 个单元测试文件、276 项通过。覆盖下载源路由、配置冲突、MCP 历史分页、中断恢复、凭据隐藏，以及已有资源不触发下载。
- 集成测试首轮仅新增工具后的三项数量断言需更新，其余通过；更新为 25 个工具后，真实 MCP/FFmpeg 专项 22 项全部通过。
- 真实便携 CPython/uv 断网测试通过：两次隔离安装复用本地 wheel 和硬链接，依赖锁带哈希，无网络请求，不修改系统 Python。
- 真实 MCP 客户端验证：源变更始终需人工确认；重试去重；界面批准后生效；过期申请不能覆盖新设置；查询、协议操作和校验失败写入历史，重启保留。

- 字幕选择专项通过：空白导入/新增字幕可编辑；手动选择优先；Ctrl/Shift 多选；独立批量样式和属性工具；保留无关字段；一次撤销；波形边界拖动在松开时提交。
- 字幕工具与预处理波形流程通过，包含逐帧输入、连续播放、双音轨、48 kHz 项目缓存、重新预处理、源码编辑及原文件保护。
