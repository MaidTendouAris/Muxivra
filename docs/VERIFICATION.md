## 边界

预计剩余时间来自实际处理进度；未开始的任务仅在存在匹配历史样本时估算。首帧前、未知时长或没有匹配样本时显示估算中/暂无估算。运行项暂停后仍占用并行名额，等待项可以重新排序。

1000 条上限用于已结束记录，所有未完成项保留。超限时清理最早结束的历史及其日志，媒体保持。删除部分批次后旧去重键拒绝返回不完整批次；整个批次清除后关联不再保留。旧版本没有保存的退出码、事件或实际执行参数不能事后恢复，详情明确标记缺失或显示原计划。

不再采用 CIM AdapterRAM。优先通过 NVIDIA 驱动读取物理总容量，否则采用并标明 DXGI 系统可用容量。共享内存上限不计入物理显存。部分驱动不提供某些性能计数器，此时显示不可用，首个 CPU/GPU 样本需等待采样。硬件信息是采集快照，设置页可更新；软件后端存在不等于驱动或显卡可用。未覆盖所有显卡、驱动、音频设备、容器、HDR 与其他操作系统。

MCP 经官方 SDK 客户端、本机 Codex CLI 配置命令与原始 HTTP JSON-RPC 验证；本次未更改用户 Codex 配置。未验证任意大模型接收提示词后的自主操作质量。AI 需要本机操作能力；远程云端无法用其 127.0.0.1 连接本机，已运行的客户端不会自动继承新的用户环境变量，部分客户端仍需重载/重启。提示词要求依据实际响应报告连接结果，不把配置写入当作连接成功。内置指南随应用版本更新，实际工具 schema 和引擎响应仍是支持范围依据。

安装包保留 Electron 必需播放 DLL 和 mpv 内部播放库，不包含 FFmpeg/ffprobe 处理引擎。应用源码包不包含上游 mpv 全部静态依赖的对应源码；公开发行安排见 resources/mpv-licenses/SOURCES.md，安装包未签名，供本地试用。
