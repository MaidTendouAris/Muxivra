# 0.25.0 验收记录

日期：2026-10-19，Windows x64。上一版精度与量化验证见 [0.24.0](history/VERIFICATION-0.24.0.md)。

## 多字幕工程

- 创建项目默认保留一个同名 ASS；项目清单维护稳定字幕 ID、文件名和当前选择，原有单 ASS 托管项目继续使用原文件。
- 编辑列表顶部以 ASS 文件下拉框替代“字幕条目”标题，右侧提供重命名、新建、删除。新建重名自动编号并继承尺寸/样式，重命名拒绝覆盖；界面与主进程均要求至少保留一个 ASS，其他列表文件被外部移除时也不能删除最后一个实际文件。
- 切换前保存当前稿件，各文件使用独立恢复会话与备份，本次打开期间分别保存撤销/重做与选择状态；当前文件重启后恢复。过期缓存不能覆盖另一文件或重建已删除文件。
- 切换字幕、样式或全文预览不重新载入媒体，播放位置保留。异步文件操作有按钮/页面处理反馈。
- 文本工具使用图标，并支持选区粗体、斜体、下划线、删除线、颜色、字号、清除格式，光标处换行与样式重置，以及整条对齐。删除旧提示语，SRT 编辑限制保留。
- “预览”二级页连续显示当前文件全部条目，可搜索全部内容、显示 ASS 标签和包含/隐藏注释，不受 50 条编辑分页限制。它核查文本与时间，复杂排版仍以视频预览为准。

## 界面语言

- 简体中文和英文；默认跟随 Windows 首选界面语言，无匹配回退英文。设置可手动覆盖，保存后即时应用，不重建播放器。
- 共享静态消息表覆盖界面、参数说明及原生文件选择框。MCP 字段、模型参数值保持原样。
- 字幕文本、用户文件名、项目名、自定义预设、模型原始输出与完整日志保留原文；内置 Markdown 指南正文保留其源语言。无互联网翻译或字幕文本 DOM 替换。
- 小窗口保留字幕列表最小高度，英文工具栏紧凑显示；字幕页整体仍不滚动，悬浮工程栏不遮挡条目或事件编辑。
