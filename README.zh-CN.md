# Muxivra

[English](README.md)

Muxivra 是一款 Windows x64 桌面媒体工具，支持视频与音频转码、批量处理、轨道管理和 SRT 字幕编辑。内置 mpv 播放器，并提供可复用的预设、统一任务队列、硬件监控和本地 MCP 服务，可通过图形界面或 AI 客户端处理媒体。

使用与技术文档见 [docs](docs/README.md)。
