# Muxivra

[English](README.md)

Muxivra 是一款 Windows x64 桌面媒体工具，支持视频与音频转码、批量处理、轨道管理和 ASS 字幕编辑，以及 SRT/SSA 导入导出。ASR 工作台可使用用户自选模型生成可编辑的字幕初稿。支持独立媒体项目管理、字幕轨道封装和画面烧录。内置 mpv 播放器，并提供可复用的预设、统一任务队列、硬件监控、GitHub Releases 应用更新和本地 MCP 服务，可通过图形界面或 AI 客户端处理媒体。

使用与技术文档见 [docs](docs/README.md)。

界面支持简体中文、英文和自动跟随系统语言；同一媒体项目可保存多个 ASS 文件，分别编辑不同语言字幕。
