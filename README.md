# Muxivra

[简体中文](README.zh-CN.md)

Muxivra is a Windows x64 desktop app for video and audio conversion, batch processing, track management, and ASS subtitle editing with SRT/SSA import and export. Its ASR workbench generates editable subtitle drafts using your own models. It also manages isolated media projects and exports subtitles as video tracks or burned into the picture. It includes an mpv player, reusable presets, a shared task queue, hardware monitoring, app updates through GitHub Releases, and a local MCP server for media processing through the GUI or an AI client.

Usage and technical documentation is available in [docs](docs/README.md).

The interface supports English and Simplified Chinese, with automatic system-language selection. A media project can keep separate ASS files for multiple subtitle languages.
