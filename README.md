# Muxivra

[简体中文](README.zh-CN.md)

Muxivra is a Windows x64 desktop app for video and audio conversion, batch processing, track management, and SRT subtitle editing. It includes an mpv player, reusable presets, a shared task queue, hardware monitoring, and a local MCP server for media processing through the GUI or an AI client.

Usage and technical documentation is available in [docs](docs/README.md).
